光配对 · Optical pairing

点击「开始光配对」后，本机会把一把随机密钥用光闪出去； 对端收到即自动完成配对，之后消息走加密通道。密钥只经过光，不经过任何网络。
原理：LED 既是发光器，也是光电二极管。
TX：GPIO 驱动 LED 闪烁（曼彻斯特编码）。
RX：ADC 采样 LED 两端微弱电压，还原比特流。

协议：0xAA×3 + LEN + PAYLOAD + XOR-CRC8
波特率：250 bps（可 menuconfig 调整）
