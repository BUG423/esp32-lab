# 💡 GlowLink

**两颗普通 LED，就能加密通话。** 无 WiFi、无蓝牙、无射频——只有光。

LED 不只是发光器：它同时也是一个光电二极管。GlowLink 让两块 ESP32 各接一颗 LED，
一颗闪、一颗「看」，就能在对视之间传数据。对准的瞬间，绿色光点亮起，字就穿过去了。

灵感来自 [SecurePair](https://github.com/toggio/SecurePair)（Hackaday 2026-10-05），
我们补上了**链路示波器可视化**、中文教程、更低的复刻门槛。

### 接线

```
        ┌──────────────┐
        │    ESP32     │
        │              │
   GPIO4├──[220Ω]──|>|──┐
        │   (TX LED)    │
        │               GND
        │              │
   GPIO34├────────|>|──┘
        │   (RX LED，可与 TX 同一颗)
       GND
```

- **TX**：GPIO4 通过 220Ω 驱动 LED
- **RX**：GPIO34（ADC1_CH6）直接读 LED 两端电压
- 两颗板子的 LED **正对** 放置，距离 2–20 cm

## 🚀 快速开始

```bash
cd firmware
idf.py set-target esp32
idf.py menuconfig     # WiFi + TX/RX 引脚 + 波特率 + Sender/Receiver
idf.py build flash monitor
```

打开 `http://glowlink.local` → 看示波器 → 输入消息 → **💡 发送**

一块板设为 **Sender**（自动 beacon），另一块 **Receiver**，互相能收到即可。

## 📡 协议

```
曼彻斯特编码 @ 250 bps（可调 50–2000）

帧结构：  0xAA 0xAA 0xAA | LEN | PAYLOAD[LEN] | XOR-CRC8
```

- **曼彻斯特**：自时钟、无直流分量，适合光信道
- **Preamble 0xAA×3**：收端同步
- **CRC8 XOR**：最简校验，坏帧丢弃并计数

## 📊 链路示波器

实时显示：
- **信号幅度**（峰峰值）
- **信噪比 SNR**
- **链路质量 0–100%**
- **误码计数**
- **原始波形**（绿色荧光线，超上镜）

现场演示时把示波器投到大屏，LED 一闪、波形一跳，效果拉满。

## ⚠️ 注意

- 强环境光（阳光、灯直射）会淹没信号——尽量在**暗一点**的环境演示
- 同一颗 LED 收发是**半双工**：同一时刻只能发或收
- 波特率越高对对准/亮度要求越高
- 这是**演示级**光通信，不是工业级光模块
